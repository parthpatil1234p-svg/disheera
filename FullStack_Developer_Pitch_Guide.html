🏛️ 2. Full-Stack Architecture Deep Dive (Judges ko Kaise Samjhana Hai)

A) Frontend Layer (Fast & Accessible)

  • Tech Stack: Vanilla JavaScript (ES6+), Semantic HTML5, CSS Grid / Flexbox.
  • Why No React? Budget 4G networks aur low-spec college laptops par React bundle size (~300KB+) FCP slow karta hai. Hamara lightweight bundle sirf ~45KB hai aur page <800ms mein render ho jata hai.
  • Visual Engine: Three.js (r128) WebGL 3D Career Constellation 60 FPS par run karta hai, aur low-power devices ke liye instant 2D SVG circular percentage gauge fallback diya gaya hai.
  • Hosting: Vercel Global Edge CDN (careerpath-ai-jade.vercel.app).

B) Backend Layer & Production Security

  • Runtime & Framework: Node.js + Express.js REST API (Hosted on Render Cloud).
  • Enterprise Security Suite:
    • Helmet.js: OWASP security HTTP headers enforce karta hai.
    • Express-Rate-Limit: Brute-force & DDoS attack protection (auth par strict 50 req/15min).
    • Stateless JWT Auth: Password bcryptjs se salted hash hota hai; plain text password database mein kabhi store nahi hota.
    • Binary Magic-Byte Inspection: Resume upload mein file extension ke bajaye binary buffer ke hex header magic-bytes check hote hain (%PDF for PDF, PK.. for DOCX) taaki malicious scripts block ho sakein.

C) Database & Cloud Storage

  • MongoDB Atlas: Multi-region cloud cluster with normalized Mongoose schemas (User, Roadmap, RoadmapTask, Attempt, Career).
  • Cloudinary API: Secure cloud storage for student resumes and avatar assets with transactional lifecycle cleanup.

🔥 3. Teen (3) "Hero" Engineering Features Jinhe Zaroor Brag Karein

1. The 60/25/15 Mathematical Match Engine (Zero Black-Box AI Bias)

Judges ko batayein ki humne career recommendations ke liye LLM prompt par guesswork nahi kiya, balki strict in-memory deterministic mathematics use ki hai:

Career Match Score = (Skill Fit × 0.60) + (Interest Overlap × 0.25) + (Academic Calibration × 0.15)

4-Tier Skill Passport Confidence Multiplier ($C_i$):

Verification Tier Multiplier Rationale
Tier 0: Self-Rated 0.70x Unverified claims par 30% discount self-reporting bias ke liye
Tier 1: Quiz-Verified 0.85x Groq LPU dynamic micro-quiz pass karne par
Tier 2: Code-Verified 1.00x GitHub public repository AST code sync se full credit
Tier 3: Interview-Verified 1.05x Spoken technical interview pass karne par bonus credit

2. Hardened Single Active Route (MongoDB Partial Unique Index)

Online learners 5 courses mein ek saath enroll hokar "Tutorial Hopping" karte hain. Humne database level par race conditions aur duplicate routes rokne ke liye invariant lagaya:

RoadmapSchema.index( { user: 1 }, { unique: true, partialFilterExpression: { status: 'active' } } );

"Lock Enrolling, Never Browsing": Student ek waqt mein sirf 1 active route par focused rehta hai, lekin explore sabhi ko kar sakta hai.

3. Two-Factor Skill Verification (Anti-Cheat Moat)

  • Factor 1 (Code Telemetry): Zero-prompt GitHub OAuth session sync — student ke repositories, language distributions aur commits scan karke [✓ Code Verified] badge deta hai.
  • Factor 2 (Dynamic AI Micro-Quiz): Groq LPU (Llama 3.3 70B) se real-time 5 technical questions synthesize hote hain <300ms mein. Pass hone par [✓ Quiz Verified] badge milta hai.
