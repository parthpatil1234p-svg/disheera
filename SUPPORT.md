## 🐛 Reporting Bugs

If you encounter unexpected behavior, UI glitches, or broken endpoints:

1. Search existing [GitHub Issues](https://github.com/parthpatil1234p-svg/disheera/issues) to avoid duplicates.
2. If the issue has not been reported, open a new issue using our **[Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md)**.
3. Include clear reproduction steps, browser/OS environment, and error logs or screenshots.
