3 Backend Services, APIs & Data Models

1. Dynamic AI Quiz Engine (Groq + Gemini + Static Fallback) server/services/aiQuizGeneratorService.js & quizService.js
  • High-Speed Groq Integration: Leverages llama-3.3-70b-versatile for sub-second question generation with strict JSON schema validation.
  • Gemini Multi-Modal Fallback: Connects to Google Gemini 2.5 Flash for high-context technical reasoning questions.
  • Domain Bank: 867-line curated fallback repository covering core competencies when offline.
2. Auth-Based GitHub Synchronization Controller server/routes/authRoutes.js & server/controllers/authController.js
  • Route: POST /api/auth/github/sync (Protected via JWT Bearer Token).
  • Identity Resolution Hierarchy:
    1. req.user.githubProfile.username → 2. req.user.githubId → 3. req.user.email prefix
  • Skill Extraction: Analyzes student repositories, extracts languages, and updates user.skills with isCodeVerified: true in MongoDB Atlas.
3. Server Process Hardening & Resilience server/server.js
  • Process Safety Handlers: Attached process.on('unhandledRejection') and process.on('uncaughtException') preventing process crashes on unhandled async events.
  • CORS & Security: Retains full localhost access (ports 5000 & 5500) and Vercel/Render production domains.
4. MongoDB Schema Enhancements server/models/User.js
  • hasCompletedSkillVerification: Boolean flag enforcing one-time verification so students aren't re-gated.
  • githubRepos: Structured collection storing analyzed repository names, stars, and primary languages.
  • quizScore & quizGaps: Tracks historical quiz assessment results and identified skill gaps.
